# 🌶️ Execution Plan v4.0.0 "Operation Ghost-Print"

**Target Designator:** Reporting & Analytics Hardening
**Objective:** Obliterate DOM bugs, inject high-contrast UI steroids, and implement zero-dependency stealth printing.

## ⚠️ Mission Briefing

### The Zero-Dependency PDF Export Strategy
We are violently rejecting heavy Python PDF libraries (like `weasyprint` or `pdfkit`). We are keeping the backend extremely lean by abusing native browser APIs.
*   **The Payload:** We trigger a stealth `window.print()` Javascript hook attached to a glass terminal button.
*   **The `@media print` Magic:** The CSS intercepts the print stream instantly. It brutally hides the sidebar, the top navbar, layout glow, and all interactive buttons (`display: none`). It strips away the dark-mode aesthetic, forces a pure black-on-white layout, and manipulates the tables so they never awkwardly slice a row in half across pages (`page-break-inside: avoid`).
*   **The Result:** A perfectly stripped, native OS "Save as PDF" dialog. Zero server-side rendering, absolute client-side perfection.

### Subbing Seaborn for Chart.js Speed
We are scrapping the Seaborn backend image-rendering idea. Serving static images from Python creates brutal bottlenecking during the login handshake.
*   **The Client-Side Flex:** Django ORM drops raw JSON straight into the template, and Chart.js rips through it in milliseconds locally on the user's machine. 
*   **Do we need an AJAX Lazy-Loader?** Not right now. Until this system is pulling 50,000+ rows instantly upon loading, traditional templating is faster. If the POS scales to enterprise levels, we will easily swap to an asynchronous AJAX loader. For now, speed is guaranteed.
